# SRA Savings — แอประบบออมทรัพย์กลุ่มอาชีพ + คลินิกแก้หนี้

แอปมือถือสำหรับ **กลุ่มอาชีพ** ใช้บันทึกและติดตามเงินออม ติดตั้งได้ทั้ง Android และ iPhone

- 💰 **บันทึกเงินออมสมาชิก** (ฝาก / ถอน) — ระบบกันถอนเกินยอดคงเหลือ
- 🧺 **รายรับ-รายจ่ายของกลุ่ม** (ขายผลผลิต เงินสนับสนุน ค่าวัตถุดิบ ค่าแรง สวัสดิการ ปันผล ฯลฯ)
- 👥 **ทะเบียนสมาชิก** แยกตามกลุ่มอาชีพ พร้อม PIN สำหรับเข้าแอป
- 📊 **แดชบอร์ดภาพรวมกลุ่มอาชีพ** — เงินออมรวม กองทุนกลุ่ม หนี้คงค้าง กราฟรายเดือน 12 เดือน เปรียบเทียบรายกลุ่ม ส่งออก CSV
- 🩺 **คลินิกแก้หนี้** — บันทึกหนี้ทุกก้อน การชำระ สัดส่วนหนี้ต่อรายได้ **แผนปลดหนี้** (คำนวณว่าหมดหนี้เมื่อไร ดอกเบี้ยเท่าไร) และบันทึกการให้คำปรึกษา
- 💬 **แชตบอตผู้ช่วยการเงิน ("น้องออม")** — ตอบคำถามเรื่องการออม หนี้ หนี้นอกระบบ การวางแผนการเงินอัตโนมัติ 24 ชม. ใช้ AI (OpenAI) ถ้าใส่คีย์ ถ้าไม่ใส่จะตอบจากคลังคำตอบ 16 เรื่องที่แก้ไขเพิ่มได้

ข้อมูลทั้งหมดเก็บใน **Google Sheet ของคุณเอง** ไม่มีค่าเซิร์ฟเวอร์ (ใช้ Google Apps Script ฟรี)

## 1. ใครทำอะไรได้

| ผู้ใช้ | เข้าแอปด้วย | ทำอะไรได้ |
|---|---|---|
| **ผู้ดูแลระบบ** (admin) | ชื่อผู้ใช้ + รหัสผ่าน | ทุกอย่างทุกกลุ่ม · เพิ่มกลุ่มอาชีพ · เพิ่มเจ้าหน้าที่ · ตั้งค่าแชตบอต/AI · แก้คลังคำตอบ · ดูคำถามที่สมาชิกถาม |
| **เจ้าหน้าที่ประจำกลุ่ม** (officer) เช่น ประธาน / เหรัญญิก | ชื่อผู้ใช้ + รหัสผ่าน | บันทึกฝาก-ถอน รายรับ-รายจ่าย สมาชิก และคลินิกหนี้ **เฉพาะกลุ่มของตน** · ดูแดชบอร์ดภาพรวมได้ทุกกลุ่ม (เป็นตัวเลขรวม ไม่เห็นข้อมูลรายคนของกลุ่มอื่น) |
| **สมาชิก** | รหัสสมาชิก + PIN | ดูยอดเงินออมและรายการของตน · เป้าหมายการออม · ภาพรวมกลุ่ม · คลินิกแก้หนี้ของตน (บันทึกหนี้/การชำระ/แผนปลดหนี้) · ถามแชตบอต · เปลี่ยน PIN |

> สมาชิก **บันทึกฝาก/ถอนเองไม่ได้** — ต้องฝากกับเจ้าหน้าที่กลุ่ม เพื่อให้ยอดเงินถูกต้องและตรวจสอบได้

| `apps-script/Code.gs` | ตั้งค่า โครงสร้างตาราง ติดตั้ง (`setup`) และการเข้าสู่ระบบ |

| `apps-script/appsscript.json` | ค่าตั้งของโปรเจกต์ Apps Script |
| `pwa/` | ตัวแอปสำหรับติดตั้งบนมือถือ (ไอคอน หน้าเปิดแอป ใช้งานแบบเต็มจอ) — แก้ `pwa/config.js` แล้วอัปขึ้นเว็บ |
| `demo/index.html` | ไฟล์ทดลองใช้ ไม่ต้องติดตั้ง มีข้อมูลตัวอย่าง |

ข้อมูลในโหมดทดลองเก็บในเบราว์เซอร์นั้นเท่านั้น และแชตบอตตอบจากคลังคำตอบ (ไม่เรียก AI)

## 4. ติดตั้งใช้งานจริง (ประมาณ 20 นาที ทำครั้งเดียว)

### ขั้นที่ 1 — สร้างฐานข้อมูลและวางโค้ด
1. เข้า Google Drive ด้วยบัญชีที่จะเป็นเจ้าของข้อมูล → **ใหม่ › Google ชีต** ตั้งชื่อ เช่น `SRA Savings — ฐานข้อมูล`
2. ในชีต เมนู **ส่วนขยาย (Extensions) › Apps Script**
3. ตั้งชื่อโปรเจกต์ (มุมซ้ายบน) เป็น `SRA Savings`
4. ไฟล์ `Code.gs` ที่มีอยู่ → ลบโค้ดเดิม แล้ววางเนื้อหาจาก `apps-script/Code.gs`
5. กด **＋ › สคริปต์** สร้าง `Api` วางจาก `Api.gs` และสร้าง `Chat` วางจาก `Chat.gs`
6. กด **＋ › HTML** สร้างไฟล์ชื่อ `App` (ตัว A ใหญ่) วางจาก `App.html`
7. ⚙ **การตั้งค่าโปรเจกต์** → ติ๊ก **แสดงไฟล์ Manifest "appsscript.json"** → กลับไปเปิด `appsscript.json` วางจากไฟล์ชื่อเดียวกัน
8. **สำคัญ:** ใน `Code.gs` แก้ `INITIAL_ADMIN_PASSWORD = 'ChangeMe@2569'` เป็นรหัสของคุณ (อย่างน้อย 8 ตัว) → **บันทึก (Ctrl+S)**
9. เลือกฟังก์ชัน **`setup`** ในแถบด้านบน → กด **▶ เรียกใช้** → อนุญาตสิทธิ์
   (ถ้าขึ้น “Google hasn’t verified this app” กด **ขั้นสูง › ไปที่ SRA Savings (ไม่ปลอดภัย) › อนุญาต** — เป็นสคริปต์ของคุณเอง)
   → กลับไปดูชีต จะเห็นแท็บ Users, Groups, Members, Savings, Ledger, Debts … และ FAQ พร้อมคำตอบเริ่มต้น

### ขั้นที่ 2 — เปิดเป็นเว็บแอป
1. ปุ่ม **การทำให้ใช้งานได้ (Deploy) › การทำให้ใช้งานได้รายการใหม่** → ⚙ เลือก **เว็บแอป**
2. **เรียกใช้ในฐานะ: ฉัน** · **ผู้มีสิทธิ์เข้าถึง: ทุกคน (Anyone)** → **Deploy**
3. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) — เปิดลิงก์นี้ในมือถือก็ใช้งานได้ทันที

> ถ้าใช้บัญชี Google Workspace ขององค์กรแล้วเลือก “ทุกคน” ไม่ได้ สมาชิกที่ไม่มีบัญชีองค์กรจะเข้าไม่ได้ → ขอฝ่ายไอทีเปิดสิทธิ์ หรือติดตั้งด้วยบัญชี Gmail ส่วนตัว

### ขั้นที่ 3 — ตั้งค่าครั้งแรกในแอป
1. เปิด URL → เลือก **เจ้าหน้าที่** → เข้าด้วย `admin` และรหัสจากขั้นที่ 1 ข้อ 8
2. **เพิ่มเติม › เปลี่ยนรหัสผ่าน** ทันที
3. **เพิ่มเติม › กลุ่มอาชีพ › ＋ เพิ่มกลุ่มอาชีพ** — ใส่ชื่อ ที่ตั้ง เงินออมต่อเดือน และเป้าหมาย
4. **เพิ่มเติม › ผู้ใช้งาน** — เพิ่มเจ้าหน้าที่ประจำแต่ละกลุ่ม (สิทธิ์ “เจ้าหน้าที่ประจำกลุ่ม” + เลือกกลุ่ม)
5. **สมาชิก › ＋ เพิ่ม** — ใส่ชื่อ เบอร์ กลุ่ม รายได้-รายจ่าย และตั้ง **PIN เริ่มต้น** แล้วแจ้งรหัสสมาชิก + PIN ให้สมาชิก (สมาชิกเปลี่ยน PIN เองได้ที่หน้า “ฉัน”)
6. **บันทึก** — บันทึกยอดยกมาของแต่ละคนเป็นรายการ “ฝาก” หนึ่งรายการ แล้วบันทึกตามจริงต่อไป
7. **เพิ่มเติม › ตั้งค่าแอป & AI** — ชื่อแอป ชื่อหน่วยงาน เบอร์ติดต่อ ชื่อแชตบอต

### ขั้นที่ 4 — (ไม่บังคับ) ให้แชตบอตตอบด้วย AI
ถ้าไม่ทำขั้นนี้ แชตบอตก็ใช้งานได้ โดยตอบจากคลังคำตอบ (แก้/เพิ่มได้ที่ **เพิ่มเติม › คลังคำตอบแชตบอต**)

1. เข้า https://platform.openai.com/api-keys → **Create new secret key** → คัดลอกคีย์ (ขึ้นต้น `sk-`)
2. ที่ **Billing / Limits** ของบัญชี OpenAI ตั้ง **วงเงินสูงสุดต่อเดือน** เพื่อกันค่าใช้จ่ายเกิน
3. ในแอป **เพิ่มเติม › ตั้งค่าแอป & AI** → วางคีย์ที่ช่อง **คีย์ OpenAI API** → ติ๊ก “ใช้ AI ตอบ” → **บันทึก** → กด **ทดสอบ AI**
4. ปรับได้: **รุ่น AI** (ค่าเริ่มต้น `gpt-4o-mini` ประหยัดและตอบภาษาไทยได้ดี), **จำนวนคำถาม AI ต่อคนต่อวัน** (เกินแล้วจะตอบจากคลังคำตอบ), และ **ข้อมูลเพิ่มเติมให้แชตบอตรู้** เช่น วันฝากเงินของกลุ่ม ระเบียบการกู้

> 🔒 **ความปลอดภัยของคีย์:** คีย์ถูกเก็บใน *Script Properties* ของโปรเจกต์ (ไม่อยู่ในโค้ด ไม่อยู่ในชีต และหน้าแอปมองไม่เห็น) — **ห้ามวางคีย์ในโค้ด ในแชต หรือในไฟล์ที่ขึ้น GitHub** ถ้าคีย์เคยหลุดไปที่ใด ให้ลบคีย์นั้นที่หน้า API keys แล้วสร้างใหม่
>
> แชตบอตจะได้รับสรุปการเงินของสมาชิกที่กำลังคุย (เงินออม หนี้คงเหลือ ดอกเบี้ย รายได้) เพื่อแนะนำได้ตรงขึ้น แต่ **ไม่ส่งชื่อ เบอร์โทร หรือรหัสสมาชิก** ไปที่ OpenAI · คำถามถูกบันทึกในแท็บ `ChatLog` (ไม่เกิน 300 ตัวอักษร) ให้ผู้ดูแลดูว่าสมาชิกสงสัยเรื่องอะไร

### ขั้นที่ 5 — ทำเป็นแอปบนมือถือ (มีไอคอน เปิดเต็มจอ)
1. เปิด `pwa/config.js` แล้ววางลิงก์จากขั้นที่ 2:
   ```js
   APP_URL: 'https://script.google.com/macros/s/XXXXXXXX/exec',
   ```
2. เอาโฟลเดอร์ `pwa` ขึ้นเว็บ (ฟรี และเป็น https ซึ่งจำเป็นสำหรับการติดตั้ง) เลือก 1 วิธี
   - **Netlify Drop (ง่ายสุด):** เข้า https://app.netlify.com/drop → ลากโฟลเดอร์ `pwa` ไปวาง → ได้ลิงก์ `https://xxxx.netlify.app` → กด Claim และเปลี่ยนชื่อได้ เช่น `sra-savings.netlify.app`
   - **GitHub Pages:** สร้าง repository ใหม่ (Public) → อัปโหลดไฟล์ทั้งหมดใน `pwa` → **Settings › Pages › Branch: main / (root) › Save** → รอ 1–2 นาที ได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
3. ส่งลิงก์ (หรือทำ QR Code) ให้สมาชิก แล้วติดตั้ง:
   - **Android (Chrome):** เปิดลิงก์ → กด **ติดตั้ง** ที่แอปเด้งขึ้น หรือ **⋮ › ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
   - **iPhone (Safari):** เปิดลิงก์ → ปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม** → **เพิ่ม**

> แก้ไฟล์ใน `pwa` ภายหลัง ให้เปลี่ยนเลขใน `pwa/sw.js` (`sra-savings-v1.0.0` → `v1.0.1`) เครื่องสมาชิกจะได้โหลดเวอร์ชันใหม่
> ถ้าต้องการลง Google Play: ใช้ https://www.pwabuilder.com สร้างไฟล์ `.aab` จากลิงก์แอป (ค่าสมัคร Play Console 25 USD ครั้งเดียว)

### อัปเดตโค้ดภายหลัง (ลิงก์เดิม)
แก้โค้ดใน Apps Script → บันทึก → **Deploy › จัดการการทำให้ใช้งานได้** → ✎ → **เวอร์ชัน: เวอร์ชันใหม่** → Deploy
(ถ้าเวอร์ชันใหม่เพิ่มคอลัมน์/แท็บ ให้รัน `setup` อีกครั้ง — ไม่ลบข้อมูลเดิม)

## 5. การใช้งานคลินิกแก้หนี้

1. เจ้าหน้าที่ใส่ **รายได้-รายจ่ายต่อเดือน** ของสมาชิก (หรือสมาชิกใส่เองที่หน้า “ฉัน”)
2. บันทึก **หนี้ทุกก้อน**: เจ้าหนี้ ประเภท ยอดคงค้าง ดอกเบี้ยต่อปี (ร้อยละ 20 ต่อเดือน = 240 ต่อปี) และยอดผ่อนต่อเดือน
3. แอปคำนวณ **หนี้ต่อรายได้**: ≤30% ปลอดภัย · 30–40% ควรระวัง · 40–50% หนัก · >50% วิกฤต และเงินที่เหลือหลังจ่ายทุกอย่าง
4. **แผนปลดหนี้**: ใส่เงินโปะเพิ่มต่อเดือน เลือก “ดอกเบี้ยสูงก่อน” (ประหยัดสุด) หรือ “ก้อนเล็กก่อน” (สร้างกำลังใจ) → เห็นเดือนที่หมดหนี้ ดอกเบี้ยรวม และลำดับการปิดหนี้ (ค่าประมาณแบบลดต้นลดดอก)
5. ทุกครั้งที่ชำระ กด **บันทึกการชำระ** — ชำระครบแล้วระบบปิดหนี้ก้อนนั้นให้อัตโนมัติ
6. เจ้าหน้าที่ **บันทึกการให้คำปรึกษา** และวันนัดครั้งถัดไป สมาชิกเห็นบันทึกนี้ในแอปของตน
7. หน้า **คลินิกหนี้** ของเจ้าหน้าที่เรียงสมาชิกที่ภาระหนี้หนักที่สุดไว้บนสุด

## 7. ความปลอดภัย
- รหัสผ่านและ PIN เก็บแบบ hash (SHA-256 + salt) · กรอกผิด 5 ครั้งล็อก 15 นาที · หมดเวลาใช้งาน 6 ชั่วโมง
- ทุกคำสั่งตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ (เจ้าหน้าที่แก้ได้เฉพาะกลุ่มตน สมาชิกเห็นเฉพาะข้อมูลตน)
- คีย์ OpenAI อยู่ใน Script Properties เท่านั้น

## 8. ปัญหาที่อาจพบ

| อาการ | วิธีแก้ |
|---|---|
| เปิดลิงก์แล้วขึ้น “ยังติดตั้งระบบไม่สำเร็จ” | รันฟังก์ชัน `setup` ในโปรแกรมแก้ไข และอนุญาตสิทธิ์ให้ครบ |
| ลืมรหัสผ่าน admin | ในโปรแกรมแก้ไข เลือก `resetAdminPassword` → ▶ เรียกใช้ (รหัสกลับเป็นค่าใน `INITIAL_ADMIN_PASSWORD`) |
| สมาชิกลืม PIN | เจ้าหน้าที่เปิด **สมาชิก › ชื่อ › ✎ แก้ไข** แล้วตั้ง PIN ใหม่ |
| แชตบอตไม่ตอบด้วย AI | ตรวจคีย์ที่หน้าตั้งค่า กด “ทดสอบ AI” · ตรวจเครดิต/วงเงินในบัญชี OpenAI · ถ้าเกินโควตาต่อวัน ระบบตอบจากคลังคำตอบ |
| แอปบนมือถือขึ้น “ตั้งค่าแอปครั้งแรก” | ยังไม่ได้ใส่ `APP_URL` ใน `pwa/config.js` หรือยังไม่ได้อัปโหลดไฟล์ใหม่ |
| คนนอกองค์กรเปิดไม่ได้ | Deploy ต้องเลือก “ทุกคน (Anyone)” |

## 9. สำหรับผู้พัฒนา
หลังแก้ไฟล์ใน `apps-script/` ให้สร้างไฟล์ทดลองใหม่:
```bash
python3 savings-app/tools/build_demo.py
```
(ใช้ตัวจำลอง Google Apps Script จาก `srayala-website/preview/preview.html` · ได้ `demo/index.html` และ `pwa/demo/index.html`)
