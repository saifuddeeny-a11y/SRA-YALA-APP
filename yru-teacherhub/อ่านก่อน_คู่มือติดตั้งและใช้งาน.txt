ห้องเรียนออนไลน์ + แฟ้มสะสมผลงานประเมิน
อาจารย์ซัยฟุดดีน แยนา · คณะครุศาสตร์ มหาวิทยาลัยราชภัฏยะลา
(Google Apps Script + Google Sheets + Google Drive)

==================================================
ไฟล์ในชุดนี้
==================================================
1) Code.gs        โค้ดฝั่งเซิร์ฟเวอร์ (วางใน Apps Script)
2) Index.html     หน้าเว็บทั้งหมด (สร้างไฟล์ HTML ชื่อ Index)
3) ทดลองใช้งาน_demo.html   เปิดในเบราว์เซอร์เพื่อทดลองได้ทันที (ข้อมูลไม่บันทึกจริง รีเฟรชแล้วหาย)
4) ประกาศ_เกณฑ์ประเมิน...pdf  ประกาศ มรย. ลงวันที่ 31 ต.ค. 2568 ที่ใช้เป็นเกณฑ์

==================================================
ติดตั้ง 3 ขั้นตอน
==================================================
1. เปิด Google Sheets (ไฟล์ใหม่หรือไฟล์เดิม) > ส่วนขยาย > Apps Script
   - ถ้าเป็นโปรเจกต์เดิม ให้ลบไฟล์เก่าทั้งหมด เหลือเพียง Code.gs
2. วางโค้ด Code.gs ทับของเดิม > กด + > HTML > ตั้งชื่อ Index > วางโค้ด Index.html > บันทึก
3. ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > ประเภท: เว็บแอป
   - ดำเนินการในฐานะ: ฉัน
   - ผู้มีสิทธิ์เข้าถึง: ทุกคน (เพื่อให้นักศึกษาเข้าได้โดยไม่ต้องล็อกอิน Google)
   - กด ทำให้ใช้งานได้ > อนุญาตสิทธิ์ > คัดลอก URL เว็บแอป
เปิด URL ครั้งแรก ระบบสร้างชีตและโฟลเดอร์ใน Drive ให้อัตโนมัติ

แก้โค้ดครั้งต่อไป: ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข (ดินสอ) > เวอร์ชัน: เวอร์ชันใหม่ > ทำให้ใช้งานได้
(URL เดิมใช้ต่อได้ ข้อมูลเดิมไม่หาย)

==================================================
การเข้าใช้งาน 3 บทบาท
==================================================
- อาจารย์: ปุ่ม "อาจารย์" มุมขวาบน รหัสเริ่มต้น Yru@2570 (ควรเปลี่ยนที่ ตั้งค่า)
- นักศึกษา: "นักศึกษาเข้าสู่ระบบ" > ลงทะเบียนด้วยรหัสนักศึกษา + รหัสเข้าเรียนรายวิชา
- ผู้ประเมิน/กรรมการ: ลิงก์เล็กใต้การ์ดหน้าแรก ใช้ "รหัสผู้ประเมิน" ที่อาจารย์ตั้งใน ตั้งค่า (ดูแฟ้มอย่างเดียว)
  * ถ้ายังไม่ตั้งรหัสผู้ประเมิน จะไม่มีใครเห็นแฟ้มประเมินนอกจากอาจารย์
  * นักศึกษามองไม่เห็นแฟ้มประเมินเลย (ป้องกันทั้งหน้าเว็บและฝั่งเซิร์ฟเวอร์)

==================================================
ฟังก์ชันหลัก
==================================================
[ห้องเรียนออนไลน์ - อาจารย์]
- สร้างรายวิชา ได้รหัสเข้าเรียน + ปุ่มคัดลอกคำเชิญ
- บทเรียน: เนื้อหา, วิดีโอ YouTube/Drive, ไฟล์/ลิงก์, เผยแพร่/ฉบับร่าง
- งาน 3 แบบ: ใบงาน (ส่งข้อความ/ไฟล์), แบบทดสอบ (ตรวจอัตโนมัติ), กิจกรรม (ให้คะแนนในชั้นเรียน)
- ตรวจงาน/ให้คะแนน/ความเห็น, งานรอตรวจ, ให้ส่งใหม่
- สมุดคะแนน (ส่งออก Excel), รายงานรายบุคคล (PDF)
- จัดการนักศึกษา: เพิ่ม/นำออก/รีเซ็ตรหัส/ระงับ
- AI ช่วยสอน: เนื้อหาบทเรียน ข้อสอบพร้อมเฉลย ใบงาน กิจกรรม rubric และร่างคะแนน/ความเห็น
  (ตั้งค่า > AI: เลือก Gemini หรือ Claude + ชื่อโมเดล + API key)
- เชื่อมรายวิชาเป็นผลงานตัวชี้วัด 2.1 / 2.2 / 2.7 ในแฟ้มประเมิน

[ห้องเรียนออนไลน์ - นักศึกษา]
- เรียนบทเรียน (ระบบบันทึกว่าเรียนแล้ว), ส่งงาน, ทำแบบทดสอบ (รู้คะแนนทันที)
- ดูคะแนน ความเห็นอาจารย์ ผลงานที่ส่ง และดาวน์โหลดรายงานคะแนน PDF

[ใหม่: ใบงานแบบตั้งคำถาม + นักศึกษาส่ง/แก้ไข/ลบงานเอง]
อาจารย์
- สร้าง/แก้ไขใบงาน > ส่วน "คำถามให้นักศึกษาพิมพ์ตอบ" > + เพิ่มคำถาม
  ใส่คะแนนรายข้อได้ (หรือเว้นว่าง), เลื่อนลำดับ/ลบข้อได้, ปุ่ม "ใช้ผลรวมเป็นคะแนนเต็ม"
  (ไม่ตั้งคำถามก็ได้ ระบบทำงานแบบเดิม: ช่องข้อความ + แนบไฟล์)
- หน้าตรวจงาน: เห็นคำถามและคำตอบของนักศึกษารายข้อ ให้คะแนนรายข้อแล้วระบบรวมคะแนนให้อัตโนมัติ
  (แก้ช่องคะแนนรวมเองได้) · เห็นป้าย "ส่งช้า" และ "แก้ไข n ครั้ง"
- ปุ่ม "ส่งคืนให้แก้ไข": เขียนความเห็นแล้วส่งคืน คำตอบเดิมยังอยู่ นักศึกษาแก้แล้วส่งกลับมาเป็นงานรอตรวจ
- ปุ่ม "ลบ/ให้ส่งใหม่": ลบงานที่ส่งทิ้ง ให้นักศึกษาเริ่มใหม่ (แบบเดิม)
- สมุดคะแนนคลิกช่องคะแนน: เห็นคำตอบรายข้อและให้คะแนนรายข้อได้เช่นกัน
นักศึกษา
- เปิดใบงาน > พิมพ์คำตอบในช่องใต้คำถามแต่ละข้อ (+ ข้อความเพิ่มเติม/แนบไฟล์ได้) > กด "ส่งงาน"
- หลังส่ง: ปุ่ม "แก้ไขงาน" (แก้คำตอบ เอาไฟล์เดิมออก/แนบไฟล์เพิ่ม แล้วกด "บันทึกการแก้ไขและส่ง")
  และปุ่ม "ลบงานที่ส่ง" (ลบคำตอบและไฟล์แนบทั้งหมด)
- แก้ไข/ลบได้จนกว่าอาจารย์จะตรวจ (ให้คะแนน) · ถ้าอาจารย์ส่งคืน จะเห็นความเห็นอาจารย์และแก้ไขได้อีกครั้ง
- ตรวจแล้วเห็นคะแนนรวม คะแนนรายข้อ และความเห็นอาจารย์
อัปเดตจากเวอร์ชันเดิม
- วาง Code.gs และ Index.html ใหม่ทับ > จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่
- ระบบเพิ่มคอลัมน์ qScores (คะแนนรายข้อ) และ editCount (จำนวนครั้งที่แก้ไข) ท้ายชีต Submissions ให้เอง
  ข้อมูลเดิมไม่หาย ใบงานเดิมที่ไม่มีคำถามใช้งานได้ตามเดิม

[แฟ้มสะสมผลงานประเมิน - อาจารย์]
- เกณฑ์ครบ 4 กลุ่ม (บริหาร/การเรียนการสอน/วิจัย/บริการวิชาการ) ทุกตัวชี้วัด 1.1–9.6
- บันทึกผลงาน + หลักฐาน (คำสั่ง หนังสือราชการ หนังสือเชิญ ลิงก์ข่าว ภาพกิจกรรม ไฟล์)
- ระบบแนะนำระดับคะแนนตามเกณฑ์ + ช่องว่างสู่ระดับถัดไป, ผู้ประเมินยืนยันระดับได้
- รายงานเลือกด้าน/เนื้อหา ดาวน์โหลด PDF / Word / Excel / ZIP หลักฐาน

==================================================
หมายเหตุ
==================================================
(1) ข้อมูลที่ไม่มี/ยังไม่ได้ระบุ
- ตำแหน่งทางวิชาการและชื่อผู้ประเมินยังไม่ได้กรอก (กรอกที่ ตั้งค่า)
- ประกาศไม่ได้กำหนดเกณฑ์รายระดับของข้อ 6 งานอื่นที่ได้รับมอบหมาย (หน้า 27)
- AI ต้องใช้ API key ของผู้ใช้เอง ถ้าไม่ใส่ ส่วนอื่นใช้งานได้ครบ
- ทดสอบครบในตัวจำลองแล้ว ส่วนที่ต้องลองบน Google จริงครั้งแรก: อัปโหลดไฟล์ขึ้น Drive,
  ส่งออก PDF/Word/Excel และการเรียก AI (แนะนำลองด้วยไฟล์เล็กก่อน)

(2) สิ่งที่ระบบกำหนดเอง/ตีความ
- ตัวชี้วัดที่ประกาศไม่ระบุคะแนนรายระดับ คิดเป็น น้ำหนัก x (ระดับที่ได้ / ระดับสูงสุด)
- ด้านรองของแต่ละกลุ่มใช้ระดับสูงสุดในด้านนั้น (ผู้ประเมินปรับได้)
- ตัวชี้วัด 4.5 (10 คะแนน) ไม่อยู่ในตารางน้ำหนักของประกาศ ระบบนับรวมให้ครบ 60
- เกรดห้องเรียน: A>=80 B+>=75 B>=70 C+>=65 C>=60 D+>=55 D>=50 F<50 (ประมาณการ)
- แบบทดสอบทำได้ 1 ครั้ง; ใบงานแก้ไข/ลบ/ส่งใหม่ได้จนกว่าอาจารย์จะตรวจ (หลังกำหนดส่งยังส่งได้ แต่ขึ้นป้าย "ส่งช้า")
- เมื่ออาจารย์ "ส่งคืนให้แก้ไข" คะแนนรายข้อและคะแนนรวมของงานนั้นจะถูกล้าง ตรวจใหม่หลังนักศึกษาส่งกลับ
- ไฟล์ที่นักศึกษาเอาออกตอนแก้ไข หรือไฟล์ของงานที่นักศึกษาลบ จะถูกย้ายไปถังขยะของ Drive (กู้คืนได้ 30 วัน)
- ไฟล์สื่อการสอน/งานนักศึกษาตั้งเป็น "ทุกคนที่มีลิงก์" เพื่อให้นักศึกษาที่ไม่ได้ล็อกอิน Google เปิดได้
- การเข้าสู่ระบบหมดอายุ: นักศึกษา 24 ชม. อาจารย์ 12 ชม. ผู้ประเมิน 8 ชม.
