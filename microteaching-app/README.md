# ห้อง Micro Teaching — เว็บไซต์บริหารจัดการห้องทดลองสอน

**เว็บไซต์** (ไม่ต้องติดตั้งแอป) สำหรับห้องทดลองสอน (Micro Teaching) คณะครุศาสตร์ มหาวิทยาลัยราชภัฏยะลา มีทั้ง **หน้าเว็บสาธารณะ** และ **ระบบหลังบ้าน**
พัฒนาต่อจากเว็บไซต์เดิม [sites.google.com/yru.ac.th/micro-teaching-yru](https://sites.google.com/yru.ac.th/micro-teaching-yru) — ใช้เมนูชุดเดิม (หน้าแรก · แบบฟอร์ม/คำร้อง · บริการ · การจัดการเรียนการสอน · ตารางการใช้ห้อง · คู่มือการใช้งาน · เกี่ยวกับเรา · ติดต่อ) แต่เพิ่มการจองห้องที่ทำงานได้จริง

**ข้อมูลทั้งหมดเก็บใน Google Sheet ของคุณ:** [ฐานข้อมูลห้อง Micro Teaching](https://docs.google.com/spreadsheets/d/1tRRr3d_jFhzs5ndiHIjJxHqPfECoblhbqXWtCPBh8js/edit) (ตั้งค่าไว้ในโค้ดแล้ว — ตัวแปร `https://docs.google.com/spreadsheets/d/1tRRr3d_jFhzs5ndiHIjJxHqPfECoblhbqXWtCPBh8js/edit_ID` ใน `apps-script/Code.gs`)

```
ผู้ใช้ ──► เว็บไซต์ (website/index.html บน Netlify / GitHub Pages / เว็บมหาวิทยาลัย)
                │  HTTPS (API_URL ใน config.js)
                ▼
          ตัวเชื่อม Apps Script ที่ผูกกับชีต (ไม่มีหน้าเว็บ — อ่าน/เขียนข้อมูล ตรวจสิทธิ์ ส่งอีเมล)
                │
                ▼
          Google Sheet ของคุณ (แท็บ Bookings, Rooms, Requests, …)
```

> ทำไมต้องมีตัวเชื่อม: เว็บไซต์เขียนลง Google Sheet ตรง ๆ ไม่ได้ (ต้องเปิดชีตให้ทุกคนแก้ไข ซึ่งไม่ปลอดภัยและผิด PDPA) ตัวเชื่อมทำงานในนามเจ้าของชีต ชีตจึงตั้งเป็น “จำกัด” ได้ ไม่มีค่าใช้จ่าย

## ความสามารถ

### หน้าเว็บสาธารณะ (ไม่ต้องเข้าสู่ระบบ)
- 🏠 **หน้าแรก**: แบนเนอร์ WELCOME / Micro Teaching, ความรู้เรื่อง Micro Teaching, ปุ่มบริการหลัก, การใช้ห้องวันนี้, ห้องให้บริการ, ข่าว, วงจรการสอนแบบจุลภาค
- 🗓️ **ตารางการใช้ห้อง** 4 มุมมอง (วันแยกรายห้อง / สัปดาห์ / เดือน / รายการ) แตะช่องว่างเพื่อจอง แสดงรายการรออนุมัติและวันปิดห้อง
- 📅 **จองห้องออนไลน์** 3 ขั้น: เลือกห้อง–วัน–ช่วงเวลาว่าง → ข้อมูลผู้จอง → รายละเอียด อุปกรณ์ ขอบันทึกวิดีโอ ได้ **รหัสการจอง** + ปุ่มเพิ่มลง Google Calendar
- 🔎 **ตรวจสอบสถานะ** ด้วยรหัส + เบอร์โทร/อีเมล: เส้นเวลาสถานะ, ยกเลิกเอง, ลิงก์ไฟล์วิดีโอ, หมายเหตุเจ้าหน้าที่, แบบประเมินความพึงพอใจ 6 ข้อ
- 📝 **ประเมินทักษะการสอน** 10 ทักษะ × 4 พฤติกรรมบ่งชี้ (ตนเอง / เพื่อน / อาจารย์) ผลสรุปรายทักษะกลับไปที่ผู้สอนทันที
- ✉️ **คำร้อง 7 ประเภท** (นอกเวลา ยืมอุปกรณ์ ขอไฟล์วิดีโอ ขอเจ้าหน้าที่ถ่ายทำ แจ้งซ่อม ขออบรม อื่น ๆ) + ติดตามผล
- 📄 หน้าเนื้อหา: บริการ · การจัดการเรียนการสอน · คู่มือ · เกี่ยวกับเรา · ระเบียบ · นโยบาย PDPA · คำถามที่พบบ่อย · ติดต่อ · เอกสารดาวน์โหลด
- 📺 **ป้ายหน้าห้อง** (`?view=display&room=…`) สำหรับแท็บเล็ต/ทีวีหน้าห้อง แสดง ว่าง/กำลังใช้ และตารางวันนี้

### ระบบหลังบ้าน (เจ้าหน้าที่ / ผู้ดูแลระบบ)
- 📊 แดชบอร์ด: งานวันนี้ รออนุมัติ คำร้องค้าง ชั่วโมงใช้งาน อัตราการใช้ห้อง ความพึงพอใจ รอแนบวิดีโอ อุปกรณ์ชำรุด กราฟ 12 เดือน
- 📋 การจอง: ค้นหา/กรอง อนุมัติ (ทีละรายการ/หลายรายการ) ไม่อนุมัติพร้อมเหตุผล เช็กอิน เช็กเอาต์ + สภาพห้อง ไม่มาใช้ห้อง แนบลิงก์วิดีโอ แก้ไข ส่งออก CSV
- 🔁 จองแทน และ **จองซ้ำรายสัปดาห์ทั้งภาคเรียน** (ข้ามวันที่ชนอัตโนมัติ)
- ✉️ คำร้อง · 🎛️ ทะเบียนอุปกรณ์ · ⛔ วันปิดห้อง · ⭐ ผลประเมิน · 📈 รายงาน (เดือน/ภาคเรียน/ปีงบประมาณ พิมพ์ PDF + CSV)
- 📝 แก้เนื้อหาหน้าเว็บ (Markdown + ตัวอย่างสด) ข่าว เอกสาร · 🏫 ห้อง · 👥 ผู้ใช้ 2 ระดับ · ⚙️ ตั้งค่ากฎการจอง/อีเมล · 🧾 บันทึกระบบ
- 📧 อีเมลอัตโนมัติ: ยืนยันการจอง ผลอนุมัติ ไฟล์วิดีโอพร้อม เตือนล่วงหน้า 1 วัน แจ้งเจ้าหน้าที่เมื่อมีรายการใหม่

## ติดตั้งใช้งานจริง (ประมาณ 20 นาที ทำครั้งเดียว)

### ขั้นที่ 1 — เชื่อม Google Sheet
1. เปิด [Google Sheet ฐานข้อมูล](https://docs.google.com/spreadsheets/d/1tRRr3d_jFhzs5ndiHIjJxHqPfECoblhbqXWtCPBh8js/edit) ด้วยบัญชีเจ้าของชีต → เมนู **ส่วนขยาย › Apps Script**
2. `Code.gs` ที่มีอยู่ → ลบโค้ดเดิม วางจาก `apps-script/Code.gs` · **＋ › สคริปต์** สร้าง `Seed`, `Api`, `Admin` วางจากไฟล์ชื่อเดียวกัน (มีแค่ 4 ไฟล์ `.gs` ไม่มีไฟล์ HTML)
3. ⚙ การตั้งค่าโปรเจกต์ → ติ๊ก “แสดงไฟล์ Manifest” → วาง `appsscript.json`
4. ใน `Code.gs` แก้ `INITIAL_ADMIN_PASSWORD` เป็นรหัสของคุณ → บันทึก
5. เลือกฟังก์ชัน **`setup`** → ▶ เรียกใช้ → อนุญาตสิทธิ์ → กลับไปดูชีต จะมีแท็บ `Settings`, `Users`, `Rooms`, `Bookings` … พร้อมเนื้อหาเริ่มต้น (แท็บ “ชีต1” ที่ว่างอยู่จะถูกลบ)
6. **การทำให้ใช้งานได้ › การทำให้ใช้งานได้รายการใหม่ › ประเภท: เว็บแอป** · เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน** → Deploy → คัดลอกลิงก์ที่ลงท้าย `/exec`
   (เปิดลิงก์นี้ในเบราว์เซอร์จะเห็น `"เชื่อมต่อฐานข้อมูลสำเร็จ"` — เป็นตัวเชื่อม ไม่ใช่หน้าเว็บ)
7. (ไม่บังคับ) รันฟังก์ชัน **`installDailyReminder`** เพื่อส่งอีเมลเตือนผู้จองล่วงหน้า 1 วัน
8. 🔒 **ในชีต กด แชร์ → การเข้าถึงทั่วไป: “จำกัด”** — เว็บไซต์ยังทำงานได้ แต่คนทั่วไปเปิดดูเบอร์โทร/อีเมลผู้จองในชีตไม่ได้ (ตอนนี้ชีตเปิดให้ “ทุกคนที่มีลิงก์” ดูได้)

### ขั้นที่ 2 — เผยแพร่เว็บไซต์
1. แก้ `website/config.js` วางลิงก์จากขั้นที่ 1 ข้อ 6:
   ```js
   API_URL: 'https://script.google.com/macros/s/AKfycb…/exec'
   ```
2. เลือกที่วางเว็บไซต์ (ฟรีทั้งหมด และเป็น https)
   - **Netlify (ง่ายที่สุด):** เข้า https://app.netlify.com/drop → ลากโฟลเดอร์ `website` ไปวาง → ได้ `https://xxxx.netlify.app` (สมัครฟรีเพื่อตั้งชื่อ เช่น `micro-teaching-yru.netlify.app`)
   - **GitHub Pages:** repository นี้ **Settings › Pages › Source: GitHub Actions** (มี workflow ให้แล้ว) — แก้ไฟล์ใน `website/` เมื่อไร เว็บอัปเดตเอง (repository ต้องเป็น Public หากใช้บัญชีฟรี)
   - **เว็บเซิร์ฟเวอร์ของมหาวิทยาลัย:** อัปโหลด `index.html` และ `config.js`
3. เปิดเว็บไซต์ → **สำหรับเจ้าหน้าที่** (ท้ายหน้า) → `admin` → เปลี่ยนรหัสผ่าน → **ตั้งค่า** (เบอร์โทร อีเมล อาคาร อีเมลเจ้าหน้าที่รับแจ้งเตือน) → แก้ **ห้อง / อุปกรณ์ / เนื้อหาเว็บ** ให้ตรงของจริง → เพิ่ม **ผู้ใช้งาน** เจ้าหน้าที่

> ⚠️ ข้อมูลห้อง อุปกรณ์ รายชื่อผู้รับผิดชอบ และเนื้อหาบางส่วนเป็น **ค่าเริ่มต้นที่ร่างจากภาพเว็บไซต์เดิม** — ตรวจและแก้ให้ตรงของจริงในหลังบ้าน (หรือแก้ในชีตโดยตรงได้ แต่ห้ามเปลี่ยนชื่อแท็บและหัวคอลัมน์แถวแรก)

### ขั้นที่ 3 — ลิงก์จาก Google Sites เดิม (ถ้ายังใช้ Google Sites อยู่)
ปุ่ม “ระบบจองห้อง” → ลิงก์ไป `https://ที่อยู่เว็บไซต์/?view=book` หรือ **แทรก › ฝัง › ฝัง URL**

| ลิงก์ลัด | เปิดหน้า |
|---|---|
| `/?view=book` | จองห้อง |
| `/?view=schedule` | ตารางการใช้ห้อง |
| `/?view=status&code=MT…` | ตรวจสอบสถานะ |
| `/?view=evaluate&code=MT…` | ประเมินการสอน |
| `/?view=display&room=<id>` | ป้ายหน้าห้อง (คัดลอกได้ที่หลังบ้าน › ห้อง) |
| `/?view=admin` | ระบบหลังบ้าน |

### อัปเดตภายหลัง
- **หน้าเว็บ:** แก้ `website/index.html` → อัปโหลดใหม่ (Netlify ลากโฟลเดอร์ซ้ำ / GitHub Pages อัปเดตเอง)
- **ตัวเชื่อม:** แก้โค้ดใน Apps Script → บันทึก → **Deploy › จัดการการทำให้ใช้งานได้** → ✎ → เวอร์ชันใหม่ → Deploy (ลิงก์ `/exec` เดิม ไม่ต้องแก้ `config.js`)

## ตารางใน Google Sheet

`Settings` · `Users` · `Rooms` · `Equipment` · `Bookings` · `Requests` · `Feedback` · `Evaluations` · `Closures` · `Pages` · `News` · `Docs` · `Log` — รายละเอียดคอลัมน์อยู่ในเอกสาร 01 หัวข้อ 9

## ความปลอดภัยและ PDPA
- รหัสผ่านเก็บแบบ hash (SHA-256 + salt) · กรอกผิด 5 ครั้งล็อก 15 นาที · session 6 ชั่วโมง · ตรวจสิทธิ์ทุกคำสั่งฝั่งเซิร์ฟเวอร์
- ตรวจเวลาซ้อนด้วย LockService (กันจองพร้อมกัน) · honeypot + จำกัดอัตราการส่งกันบอต
- ตารางสาธารณะ/ป้ายหน้าห้อง **ไม่แสดงชื่อและเบอร์โทร** เป็นค่าเริ่มต้น · ผู้จองต้องยอมรับระเบียบและนโยบายข้อมูลส่วนบุคคลก่อนส่ง
- ตั้งค่าแชร์ Google Sheet เป็น **“จำกัด”** (เว็บไซต์เข้าผ่านตัวเชื่อม ไม่ต้องเปิดชีต) · สำรองข้อมูลด้วย ไฟล์ › ทำสำเนา
- ตัวเชื่อมรับเฉพาะคำสั่งที่อนุญาต ฟังก์ชันภายในเรียกจากภายนอกไม่ได้
