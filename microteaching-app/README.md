# ห้อง Micro Teaching — ระบบบริหารจัดการห้องทดลองสอน

ระบบเว็บ **หน้าบ้าน + หลังบ้าน** สำหรับห้องทดลองสอน (Micro Teaching) คณะครุศาสตร์ มหาวิทยาลัยราชภัฏยะลา
พัฒนาต่อจากเว็บไซต์เดิม [sites.google.com/yru.ac.th/micro-teaching-yru](https://sites.google.com/yru.ac.th/micro-teaching-yru) — ใช้เมนูชุดเดิม (หน้าแรก · แบบฟอร์ม/คำร้อง · บริการ · การจัดการเรียนการสอน · ตารางการใช้ห้อง · คู่มือการใช้งาน · เกี่ยวกับเรา · ติดต่อ) แต่เพิ่มระบบจองห้องที่ทำงานได้จริงพร้อมระบบหลังบ้าน

ฐานข้อมูลคือ **Google Sheet** และเซิร์ฟเวอร์คือ **Google Apps Script** ของหน่วยงานเอง จึง **ไม่มีค่าเซิร์ฟเวอร์** และฝังใน Google Sites ได้

## ความสามารถ

### หน้าเว็บสาธารณะ (ไม่ต้องเข้าสู่ระบบ)
- 🏠 **หน้าแรก**: แบนเนอร์ WELCOME / Micro Teaching, ความรู้เรื่อง Micro Teaching, ปุ่มบริการหลัก, การใช้ห้องวันนี้, ห้องให้บริการ, ข่าว, วงจรการสอนแบบจุลภาค
- 🗓️ **ตารางการใช้ห้อง** 4 มุมมอง (วันแยกรายห้อง / สัปดาห์ / เดือน / รายการ) แตะช่องว่างเพื่อจอง แสดงรายการรออนุมัติและวันปิดห้อง
- 📅 **จองห้องออนไลน์** 3 ขั้น: เลือกห้อง–วัน–ช่วงเวลาว่าง → ข้อมูลผู้จอง → รายละเอียด อุปกรณ์ ขอบันทึกวิดีโอ ได้ **รหัสการจอง** + ปุ่มเพิ่มลง Google Calendar
- 🔎 **ตรวจสอบสถานะ** ด้วยรหัส + เบอร์โทร/อีเมล: เส้นเวลาสถานะ, ยกเลิกเอง, ลิงก์ไฟล์วิดีโอ, หมายเหตุเจ้าหน้าที่, แบบประเมินความพึงพอใจ 6 ข้อ
- 📝 **ประเมินทักษะการสอน** 10 ทักษะ × 4 พฤติกรรมบ่งชี้ (ตนเอง / เพื่อน / อาจารย์) ผลสรุปรายทักษะกลับไปที่ผู้สอนทันที
- ✉️ **คำร้อง 7 ประเภท** (นอกเวลา ยืมอุปกรณ์ ขอไฟล์วิดีโอ ขอเจ้าหน้าที่ถ่ายทำ แจ้งซ่อม ขออบรม อื่น ๆ) + ติดตามผล
- 📄 หน้าเนื้อหา: บริการ · การจัดการเรียนการสอน · คู่มือ · เกี่ยวกับเรา · ระเบียบ · นโยบาย PDPA · คำถามที่พบบ่อย · ติดต่อ · เอกสารดาวน์โหลด
- 📺 **ป้ายหน้าห้อง** (`?view=display&room=…`) สำหรับแท็บเล็ต/ทีวีหน้าห้อง แสดง ว่าง/กำลังใช้ และตารางวันนี้

### ระบบหลังบ้าน (เจ้าหน้าที่ / ผู้ดูแลระบบ)
- 📊 แดชบอร์ด: งานวันนี้ รออนุมัติ คำร้องค้าง ชั่วโมงใช้งาน อัตราการใช้ห้อง ความพึงพอใจ รอแนบวิดีโอ อุปกรณ์ชำรุด กราฟ 12 เดือน
- 📋 การจอง: ค้นหา/กรอง อนุมัติ (ทีละรายการ/หลายรายการ) ไม่อนุมัติพร้อมเหตุผล เช็กอิน เช็กเอาต์ + สภาพห้อง ไม่มาใช้ห้อง แนบลิงก์วิดีโอ แก้ไข ส่งออก CSV
- 🔁 จองแทน และ **จองซ้ำรายสัปดาห์ทั้งภาคเรียน** (ข้ามวันที่ชนอัตโนมัติ)
- ✉️ คำร้อง · 🎛️ ทะเบียนอุปกรณ์ · ⛔ วันปิดห้อง · ⭐ ผลประเมิน · 📈 รายงาน (เดือน/ภาคเรียน/ปีงบประมาณ พิมพ์ PDF + CSV)
- 📝 แก้เนื้อหาหน้าเว็บ (Markdown + ตัวอย่างสด) ข่าว เอกสาร · 🏫 ห้อง · 👥 ผู้ใช้ 2 ระดับ · ⚙️ ตั้งค่ากฎการจอง/อีเมล · 🧾 บันทึกระบบ
- 📧 อีเมลอัตโนมัติ: ยืนยันการจอง ผลอนุมัติ ไฟล์วิดีโอพร้อม เตือนล่วงหน้า 1 วัน แจ้งเจ้าหน้าที่เมื่อมีรายการใหม่

| `apps-script/Admin.gs` | ฟังก์ชันหลังบ้าน (อนุมัติ เช็กอิน จองซ้ำ คำร้อง ห้อง อุปกรณ์ เนื้อหา ผู้ใช้ ตั้งค่า) |
| `apps-script/Seed.gs` | ข้อมูลเริ่มต้น: เนื้อหาทุกหน้า ห้อง 4 ห้อง อุปกรณ์ 15 รายการ เอกสาร 8 รายการ |
| `apps-script/App.html` | หน้าเว็บทั้งหมด (หน้าบ้าน + หลังบ้าน) |
| `apps-script/appsscript.json` | ค่าตั้งโปรเจกต์ Apps Script |
| `demo/index.html` | ไฟล์ทดลองใช้พร้อมข้อมูลตัวอย่าง (รันโค้ดจริงในเบราว์เซอร์) |
| `docs/01-เอกสารวิเคราะห์และออกแบบระบบ.pdf/.docx` | วิเคราะห์แนวปฏิบัติจากทั่วโลก ความต้องการ (FR/NFR) workflow สถาปัตยกรรม data dictionary PDPA KPI แผนนำไปใช้ |
| `docs/02-คู่มือการใช้งาน.pdf/.docx` | คู่มือผู้ขอใช้ห้อง เจ้าหน้าที่ ผู้ดูแล การติดตั้ง SOP และปัญหาที่พบบ่อย (มีภาพหน้าจอ) |
| `docs/03-ระเบียบและแบบฟอร์ม.pdf/.docx` | ร่างประกาศระเบียบการใช้ห้อง + แบบฟอร์ม MT-01 ถึง MT-08 |
| `tools/build_demo.py` · `tools/build_docs.py` | สร้างไฟล์ทดลองใช้ / เอกสารใหม่หลังแก้โค้ด |

## ทดลองใช้ก่อนติดตั้ง

```bash
cd microteaching-app && python3 -m http.server 8000
```

เปิด `http://localhost:8000/demo/` (ข้อมูลอยู่ในเบราว์เซอร์นั้นเท่านั้น กด “รีเซ็ตข้อมูล” ที่แถบล่างเพื่อเริ่มใหม่)

| ทดลอง | ข้อมูล |
|---|---|
| ตรวจสอบสถานะ / ประเมินการสอน | รหัส `MT-DEMO1` · เบอร์ `0812345678` |
| เจ้าหน้าที่ | `staff1` / `demo12345` |
| ผู้ดูแลระบบ | `admin` / `ChangeMe@2569` |

## ติดตั้งใช้งานจริง (ประมาณ 15 นาที)

1. Google Drive (แนะนำบัญชีกลางของห้อง) → **ใหม่ › Google ชีต** → เมนู **ส่วนขยาย › Apps Script**
2. วาง `Code.gs` แทนของเดิม · **＋ › สคริปต์** สร้าง `Seed`, `Api`, `Admin` · **＋ › HTML** สร้าง `App` (วางจากไฟล์ชื่อเดียวกัน)
3. ⚙ การตั้งค่าโปรเจกต์ → ติ๊ก “แสดงไฟล์ Manifest” → วาง `appsscript.json`
4. ใน `Code.gs` แก้ `INITIAL_ADMIN_PASSWORD` → บันทึก → เลือกฟังก์ชัน **`setup`** → ▶ เรียกใช้ → อนุญาตสิทธิ์
5. **Deploy › การทำให้ใช้งานได้รายการใหม่ › เว็บแอป** · เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน** (หรือทุกคนใน yru.ac.th) → คัดลอก URL `/exec`
6. (ไม่บังคับ) รันฟังก์ชัน **`installDailyReminder`** เพื่อส่งอีเมลเตือนผู้จองล่วงหน้า 1 วัน
7. เปิด URL → **สำหรับเจ้าหน้าที่** (ท้ายหน้า) → `admin` → เปลี่ยนรหัสผ่าน → **ตั้งค่า** (เบอร์โทร อีเมล อาคาร อีเมลเจ้าหน้าที่รับแจ้งเตือน) → แก้ **ห้อง / อุปกรณ์ / เนื้อหาเว็บ** ให้ตรงของจริง → เพิ่ม **ผู้ใช้งาน** เจ้าหน้าที่

> ⚠️ ข้อมูลห้อง อุปกรณ์ รายชื่อผู้รับผิดชอบ และเนื้อหาบางส่วนเป็น **ค่าเริ่มต้นที่ร่างจากภาพเว็บไซต์เดิม** (ระบบเข้าถึงเว็บไซต์เดิมโดยตรงไม่ได้) — กรุณาตรวจและแก้ให้ตรงของจริงในหลังบ้านก่อนเปิดใช้

### ฝังใน Google Sites เดิม
แก้ไขเว็บไซต์ → **แทรก › ฝัง › ฝัง URL** → วาง URL `/exec` (หรือใช้ปุ่มลิงก์เปิดเต็มหน้า)

| ลิงก์ลัด | เปิดหน้า |
|---|---|
| `…/exec?view=book` | จองห้อง (ใช้กับปุ่ม “ระบบจองห้อง”) |
| `…/exec?view=schedule` | ตารางการใช้ห้อง |
| `…/exec?view=status&code=MT…` | ตรวจสอบสถานะ |
| `…/exec?view=evaluate&code=MT…` | ประเมินการสอน |
| `…/exec?view=display&room=<id>` | ป้ายหน้าห้อง (คัดลอกได้ที่หลังบ้าน › ห้อง) |
| `…/exec?view=admin` | ระบบหลังบ้าน |

### อัปเดตโค้ดภายหลัง
แก้โค้ด → บันทึก → **Deploy › จัดการการทำให้ใช้งานได้** → ✎ → เวอร์ชันใหม่ → Deploy (URL เดิม ข้อมูลเดิมไม่หาย)

## ตารางใน Google Sheet

`Settings` · `Users` · `Rooms` · `Equipment` · `Bookings` · `Requests` · `Feedback` · `Evaluations` · `Closures` · `Pages` · `News` · `Docs` · `Log` — รายละเอียดคอลัมน์อยู่ในเอกสาร 01 หัวข้อ 9

## ความปลอดภัยและ PDPA
- รหัสผ่านเก็บแบบ hash (SHA-256 + salt) · กรอกผิด 5 ครั้งล็อก 15 นาที · session 6 ชั่วโมง · ตรวจสิทธิ์ทุกคำสั่งฝั่งเซิร์ฟเวอร์
- ตรวจเวลาซ้อนด้วย LockService (กันจองพร้อมกัน) · honeypot + จำกัดอัตราการส่งกันบอต
- ตารางสาธารณะ/ป้ายหน้าห้อง **ไม่แสดงชื่อและเบอร์โทร** เป็นค่าเริ่มต้น · ผู้จองต้องยอมรับระเบียบและนโยบายข้อมูลส่วนบุคคลก่อนส่ง
- อย่าแชร์สิทธิ์แก้ไข Google Sheet ให้บุคคลทั่วไป · สำรองข้อมูลด้วย ไฟล์ › ทำสำเนา
