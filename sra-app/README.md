# แอป SRA YALA — กองทุนออมทรัพย์และบัญชีฮัจย์-อุมเราะห์

แอปมือถือ (PWA) ที่เปิดระบบเดิมของคุณแบบแอป ติดตั้งได้ทั้ง **Android** และ **iPhone** มีไอคอนบนหน้าจอ เปิดแบบเต็มจอ และมีเมนูด้านล่าง

> **ข้อมูลไม่ได้ย้ายไปไหน** ทั้งสมาชิก ยอดเงิน แบบฟอร์ม และข่าว ยังอยู่ใน Google Sheet เดิมครบถ้วน แอปแค่เปิดระบบ Apps Script เดิม
> เมื่อแก้อะไรในหลังบ้านหรือในโค้ด Apps Script แอปจะเห็นของใหม่ทันที โดยไม่ต้องอัปเดตแอป

ปุ่มย้อนกลับของมือถือใช้ได้ ถ้าไม่มีอินเทอร์เน็ตจะขึ้นหน้าแจ้งเตือน และบนคอมพิวเตอร์เมนูจะย้ายไปอยู่ด้านซ้าย

## ติดตั้งให้ใช้งานจริง (ทำครั้งเดียว ประมาณ 15 นาที)

### ขั้นที่ 1: อัปเดต Apps Script (ระบบเดิม)
1. แทนที่ไฟล์ `Code.gs` ในโปรเจกต์ด้วยไฟล์จากโฟลเดอร์ `srayala-website/apps-script/` ไฟล์ใหม่เพิ่มส่วนที่ให้ลิงก์ในระบบเปิดอยู่ในแอป ไม่หลุดออกไปเบราว์เซอร์ ส่วนอื่นยังเหมือนเดิม
2. ไปที่ **Deploy › Manage deployments** กด ✏️ เลือก **Version: New version** แล้วกด **Deploy**
3. ตรวจว่า **Who has access = Anyone (ทุกคน)**
   ถ้าเลือกได้แค่ "ทุกคนใน yru.ac.th" สมาชิกที่ไม่มีอีเมลมหาวิทยาลัยจะเปิดแอปไม่ได้ ให้ติดต่อฝ่ายไอทีของมหาวิทยาลัย หรือ Deploy ด้วยบัญชี Gmail ส่วนตัวแทน
4. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### ขั้นที่ 2: ใส่ลิงก์ในแอป
เปิดไฟล์ `config.js` แล้ววางลิงก์จากขั้นที่ 1
```js
APP_URL: 'https://script.google.com/macros/s/XXXXXXXX/exec',
START: 'member',   // 'member' = เปิดแอปแล้วเข้าหน้าสมาชิก, 'site' = หน้าแรกเว็บไซต์
```

### ขั้นที่ 3: เอาแอปขึ้นเว็บ (ฟรี) เลือก 1 วิธี

**วิธี A: Netlify Drop (ง่ายที่สุด ไม่ต้องสมัครก่อน)**
1. เข้า https://app.netlify.com/drop
2. ลากโฟลเดอร์ `sra-app` ทั้งโฟลเดอร์ไปวาง
3. ได้ลิงก์ เช่น `https://xxxx.netlify.app` กด **Claim** เพื่อเก็บไว้ในบัญชี และเปลี่ยนชื่อเว็บเป็น `sra-yala.netlify.app` ได้

**วิธี B: GitHub Pages**
1. สมัคร/เข้าสู่ระบบที่ https://github.com แล้วกด **New repository** ตั้งชื่อ `sra-app` และเลือก **Public**
2. กด **uploading an existing file** ลากไฟล์ทั้งหมดใน `sra-app` ไปวาง แล้วกด **Commit changes**
3. ไปที่ **Settings › Pages › Branch: main / (root)** แล้วกด **Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/sra-app/`

> แอปต้องเปิดผ่าน **https** เท่านั้นจึงจะติดตั้งได้ ทั้ง 2 วิธีให้ https มาอยู่แล้ว
> ก่อนเผยแพร่จะลบโฟลเดอร์ `demo` ออกก็ได้ เพราะใช้แค่ทดลอง

### ขั้นที่ 4: ติดตั้งลงมือถือ (ส่งขั้นตอนนี้ให้สมาชิก)
- **Android (Chrome):** เปิดลิงก์แอป แล้วกดปุ่ม **"ติดตั้ง"** ที่แอปเด้งขึ้นมา หรือกด **⋮ › ติดตั้งแอป**
- **iPhone (Safari):** เปิดลิงก์แอป แล้วกด **แชร์ › เพิ่มไปยังหน้าจอโฮม › เพิ่ม**
- ในแอปมีวิธีติดตั้งอธิบายไว้ที่เมนู **⋯ เพิ่มเติม › ติดตั้งแอปลงเครื่อง**

แนะนำให้ทำ **QR Code** ของลิงก์แอปติดไว้ที่กลุ่ม หรือแนบไปกับใบแจ้งรหัสสมาชิก

## ทดลองก่อนติดตั้ง
ถ้า `config.js` ยังไม่มีลิงก์ แอปจะขึ้นหน้า "ตั้งค่าแอปครั้งแรก" และมีปุ่ม **"ทดลองด้วยข้อมูลตัวอย่าง"** (ใช้ไฟล์ใน `demo/`)
- สมาชิกตัวอย่าง: `M0001` / `demo1234`
- หลังบ้าน: `admin` / `SraYala@2569`

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ เช่นอัปขึ้น Netlify ก่อน หรือรันในเครื่องด้วย `python3 -m http.server` แล้วเปิด `http://localhost:8000` ดับเบิลคลิกเปิดไฟล์ตรง ๆ จะใช้ไม่ได้

## (ไม่บังคับ) ลง Google Play Store
1. เข้า https://www.pwabuilder.com แล้ววางลิงก์แอป
2. เลือก **Android › Generate Package** จะได้ไฟล์ `.aab` และ `assetlinks.json`
3. วาง `assetlinks.json` ไว้ที่ `https://โดเมนของคุณ/.well-known/assetlinks.json` (ใช้ Netlify หรือโดเมนของตัวเองจะง่ายกว่า GitHub Pages)
4. สมัคร Google Play Console (ค่าธรรมเนียมครั้งเดียว 25 USD) แล้วอัปโหลด `.aab`

สำหรับ iPhone แนะนำให้ติดตั้งผ่าน **เพิ่มไปยังหน้าจอโฮม** ตามขั้นที่ 4 เพราะ App Store มักไม่รับแอปที่เปิดเว็บอย่างเดียว

## ไฟล์ในโฟลเดอร์นี้
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอป (หน้าเปิดแอป เมนูล่าง หน้าออฟไลน์ แจ้งติดตั้ง) |
| `config.js` | **ตั้งค่าลิงก์ระบบ** แก้ไฟล์นี้ไฟล์เดียว |
| `manifest.webmanifest` | ชื่อแอป สี ไอคอน ทางลัด (กดค้างที่ไอคอนบน Android) |
| `sw.js` | ทำให้แอปเปิดเร็วและรองรับออฟไลน์ (ไม่เก็บข้อมูลสมาชิกในเครื่อง) |
| `icons/` | ไอคอนแอปทุกขนาด ถ้าจะใช้โลโก้ของตัวเอง ให้แทนไฟล์โดยใช้ชื่อและขนาดเดิม |
| `demo/` | ระบบตัวอย่างสำหรับทดลอง ลบออกได้ |

ถ้าแก้ไฟล์แอปภายหลัง ให้เปลี่ยนเลขใน `sw.js` (`sra-app-v1.0.0` เป็น `v1.0.1`) เครื่องของสมาชิกจะได้โหลดเวอร์ชันใหม่
