## 2.1 ระบบสมาชิกกองทุน (ใหม่): `URL เว็บ?mode=member`

หน้าเข้าสู่ระบบสมาชิกแยกจากหน้าเว็บ แต่ใช้ฐานข้อมูลเดียวกัน หน้าเว็บมีปุ่ม **“เข้าสู่ระบบสมาชิก”** มุมขวาบน และมีแถบ **กองทุนออมทรัพย์และบัญชีฮัจย์-อุมเราะห์** บนหน้าแรก

| สมาชิกทำอะไรได้ | หลังบ้านทำอะไรได้ |
|---|---|
| เข้าสู่ระบบด้วย **รหัสสมาชิก + รหัสผ่าน** (ต้องเปลี่ยนรหัสเริ่มต้นเมื่อเข้าครั้งแรก) | **สมาชิกกองทุน**: เพิ่ม/แก้ไข/ระงับสมาชิก, รีเซ็ตรหัสผ่าน, ตั้งเป้าหมายการออม, **นำเข้าหลายคน** (วางจาก Excel), ส่งออก CSV |
| ดูยอดคงเหลือ 3 บัญชี: **เงินออมทรัพย์ · บัญชีฮัจย์ · บัญชีอุมเราะห์** พร้อมแถบความก้าวหน้าสู่เป้าหมาย | **บันทึกเงินออม**: บันทึกฝาก/ถอนให้สมาชิก (กันถอนเกินยอด), ตัวกรองบัญชี/สถานะ/เดือน, ส่งออก CSV |
| ดูรายการเคลื่อนไหว กรองตามบัญชี/ปี และ **พิมพ์รายการ** | **อนุมัติ/ไม่อนุมัติ** รายการที่สมาชิกแจ้งฝาก พร้อมเปิดดูสลิป |
| **แจ้งฝากเงิน** พร้อมแนบสลิป (รอเจ้าหน้าที่อนุมัติ ยอดจึงจะเข้าบัญชี) | **ตั้งค่าเว็บไซต์ › ระบบสมาชิกกองทุน**: ชื่อกองทุน ชื่อบัญชีทั้ง 3 ประกาศหน้าเข้าสู่ระบบ เปิด/ปิดการแจ้งฝาก |
| กรอก **แบบฟอร์มสำหรับสมาชิก** (เช่น บันทึกรายรับ-รายจ่ายครัวเรือน) และเปลี่ยนรหัสผ่าน | อีเมลแจ้งเตือนเมื่อสมาชิกแจ้งฝาก / มีคำตอบแบบฟอร์มใหม่ |

สลิปเก็บในโฟลเดอร์ Drive `Slips` แบบ **ไม่แชร์สาธารณะ** (เปิดได้เฉพาะเจ้าของ Drive) ส่วนรหัสผ่านสมาชิกเก็บแบบ hash และระบบล็อก 15 นาทีเมื่อกรอกผิด 5 ครั้ง

## 2.2 แบบฟอร์มออนไลน์ที่บันทึกลงชีต (ใหม่)

- หน้าเว็บ: **คลังความรู้ › แบบฟอร์มออนไลน์** (`?page=forms`) และแสดงในหน้า “เครื่องมือ”
- หลังบ้าน **แบบฟอร์มออนไลน์**: สร้าง/แก้ไขแบบฟอร์มเอง (ข้อความ ตัวเลข วันที่ เบอร์โทร อีเมล dropdown เลือก 1 ข้อ เลือกหลายข้อ หัวข้อส่วน), กำหนดว่าทุกคนกรอกได้หรือเฉพาะสมาชิก, เปิด/ปิดรับ, ดูคำตอบ, ทำเครื่องหมายตรวจแล้ว, **ส่งออก CSV**
- แบบฟอร์มเริ่มต้น 3 ชุด: **ใบสมัครสมาชิกกองทุน**, **แบบสำรวจหนี้สินครัวเรือน**, **บันทึกรายรับ-รายจ่ายครัวเรือน** (สำหรับสมาชิก) — แก้ไขคำถามได้ที่หลังบ้าน

## 3. ชีต (แท็บ) ที่ระบบจะสร้างใน Google Sheet

| แท็บ | เก็บอะไร | แท็บ | เก็บอะไร |
|---|---|---|---|
| Settings | ตั้งค่าเว็บ | Reports | **รายงานผลดำเนินการ** |
| Pages | หัวข้อ/เนื้อหาแต่ละหน้า | KPIs | **ตัวชี้วัด** |
| Groups | กลุ่มอาชีพ | Albums | **อัลบั้มภาพ** |
| News | ข่าว กิจกรรม ประชาสัมพันธ์ | Gallery | ภาพในทุกอัลบั้ม |
| Documents | เอกสาร + เครื่องมือ (คอลัมน์ `kind`) | Media | บันทึกไฟล์ที่อัปโหลดทั้งหมด |
| Links, Indicators, Steps | ลิงก์ ตัวเลข ขั้นตอน | Messages, Users, Logs | ข้อความ ผู้ใช้ ประวัติ |
| **Members** | สมาชิกกองทุน (รหัสผ่านแบบ hash) | **Transactions** | รายการฝาก/ถอน 3 บัญชี |

> แนะนำให้แก้ข้อมูลผ่านหลังบ้าน ถ้าแก้ในชีตโดยตรง ให้กด “ล้างแคช” ในหลังบ้านหลังแก้
> **อย่าแชร์สิทธิ์แก้ไขชีตนี้ให้คนทั่วไป** (แท็บ Users มีข้อมูลบัญชีผู้ดูแล) และอย่าเปลี่ยนชื่อแท็บ/หัวคอลัมน์

## 4. ขั้นตอนติดตั้ง (ประมาณ 15 นาที)

ใช้บัญชี **@yru.ac.th ที่เป็นเจ้าของหรือมีสิทธิ์แก้ไข** Google Sheet “เว็บไซต์แก้จนใหม่”

1. เปิด Google Sheet “เว็บไซต์แก้จนใหม่” → เมนู **ส่วนขยาย (Extensions) › Apps Script**
2. ตั้งชื่อโปรเจกต์ (มุมซ้ายบน) เป็น `SRA YALA Website`
3. **ไฟล์สคริปต์** (ปุ่ม ＋ › สคริปต์):
   - `Code.gs` (มีอยู่แล้ว) → ลบโค้ดเดิม วางเนื้อหาจาก `Code.gs`
   - สร้าง `Api` → วางจาก `Api.gs`
   - สร้าง `Seed` → วางจาก `Seed.gs`
   - สร้าง `Member` → วางจาก `Member.gs`
4. **ไฟล์ HTML** (ปุ่ม ＋ › HTML) ตั้งชื่อตรงตัวพิมพ์: `Index`, `Admin`, `Theme`, `Member`, `FormKit` → วางจากไฟล์ชื่อเดียวกัน
5. ⚙ **การตั้งค่าโปรเจกต์** → ติ๊ก “แสดงไฟล์ Manifest appsscript.json” → กลับมาเปิด `appsscript.json` → วางเนื้อหาจากไฟล์ `appsscript.json`
6. (แนะนำ) ใน `Code.gs` เปลี่ยน `INITIAL_ADMIN_PASSWORD = 'SraYala@2569'` เป็นรหัสของท่าน → **บันทึก (Ctrl+S)**
7. เลือกฟังก์ชัน **`setup`** → กด **▶ เรียกใช้** → อนุญาตสิทธิ์ (ถ้าขึ้น “Google hasn’t verified this app” กด **ขั้นสูง › ไปที่ SRA YALA Website › อนุญาต**)
   → กลับไปดู Google Sheet จะเห็นแท็บ Settings, Pages, News, Reports ฯลฯ พร้อมข้อมูลเริ่มต้น
8. **การทำให้ใช้งานได้ › การทำให้ใช้งานได้รายการใหม่** → ⚙ **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน** → **Deploy** → คัดลอก URL (`…/exec`)
9. เปิด URL = **หน้าเว็บ** · `URL?mode=member` = **ระบบสมาชิก** · เปิด `URL?mode=admin` = **หลังบ้าน** → ล็อกอิน `admin` / รหัสจากข้อ 6 → เปลี่ยนรหัสผ่านทันทีที่ **ตั้งค่าเว็บไซต์**

### ทำต่อหลังติดตั้ง (ให้เว็บพร้อมใช้งานเต็มที่)

0. **สมาชิกกองทุน** — เพิ่มสมาชิก (หรือ “นำเข้าหลายคน”) พร้อมรหัสผ่านเริ่มต้น แล้วบันทึกยอดยกมาของแต่ละบัญชีที่ **บันทึกเงินออม** → แจ้งรหัสสมาชิกและลิงก์ `URL?mode=member` ให้สมาชิก

1. **ตั้งค่าเว็บไซต์ › ย้ายภาพเข้า Drive** — กดซ้ำจนขึ้น “ครบแล้ว”
2. **รายงานผลดำเนินการ** — เติมปีงบประมาณ วันที่ ผู้เข้าร่วม งบประมาณ และแนบไฟล์รายงานฉบับเต็มของแต่ละกิจกรรม
3. **ตัวชี้วัด** — ใส่ค่าเป้าหมาย (ตอนนี้มีแต่ผลที่ได้) และเพิ่มตัวชี้วัดของโครงการ
4. **คลังภาพ** — สร้างอัลบั้มต่อกิจกรรม แล้วอัปโหลดภาพ
5. **เอกสาร & เครื่องมือ** — อัปโหลดเอกสาร/คู่มือ/แบบฟอร์มที่ต้องการให้ดาวน์โหลด
6. **กลุ่มอาชีพ** — ใส่ภาพหน้าปกของแต่ละกลุ่ม

## 7. ความปลอดภัย

รหัสผ่านเก็บแบบ hash (SHA-256 + salt) · ทุกคำสั่งหลังบ้านตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ · กรองแท็กอันตรายใน HTML · ล็อกการล็อกอินผิดเกิน 10 ครั้ง · แบบฟอร์มติดต่อกันบอท · บันทึกประวัติทุกการแก้ไข

## 8. ข้อมูลเริ่มต้นที่ควรตรวจทาน

- **รายงานผลดำเนินการ 4 รายการ** เรียบเรียงจากกิจกรรมที่เผยแพร่บนเว็บเดิม (ยกระดับการบริหารกองทุน, พบปะธนาคาร/สหกรณ์, รางวัลอัลฮัจย์และอุมเราะห์ 2568, สำรวจหนี้/พัฒนา ADM) — ยังไม่มีตัวเลขผู้เข้าร่วม/งบประมาณ และรายการที่ 4 ตั้งสถานะ “กำลังดำเนินการ” ไว้ก่อน
- **ตัวชี้วัด 3 รายการ** (กลุ่มอาชีพ 3, สมาชิก 80 คน, อบต. 5 แห่ง) ยังไม่มีค่าเป้าหมาย
- **เครื่องมือ 4 รายการ** = แบบสำรวจหนี้ครัวเรือน, ระบบบันทึกข้อมูลการเงินครัวเรือน, Dashboard (Canva), แบบฟอร์มรับสมัคร ADM (ลิงก์จากเว็บเดิม)
- หมวดข่าวเดิมจัดใหม่เป็น ข่าว / กิจกรรม / ประชาสัมพันธ์ และยังไม่มีวันที่ข่าว
- ข้อความกลุ่มอาชีพ ที่อยู่มหาวิทยาลัย ขั้นตอนกระบวนการ และคำอธิบายโมเดล เรียบเรียงใหม่ — ตรวจทานได้ที่หลังบ้าน
